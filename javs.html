PoC: Address Bar Spoofing

Tujuan: membuktikan address bar bisa menampilkan URL (google.com) yang tidak sesuai dengan konten halaman milik attacker. Buka file ini di Mi Browser, lalu coba tiap varian. Bandingkan dengan Chrome.
HANYA untuk pengujian keamanan. Konten palsu di bawah sengaja diberi label jelas agar tidak disalahgunakan.

Varian A — Navigation Race

Cara kerja: halaman mulai navigasi ke google.com lalu — sebelum navigasi selesai — menimpa dokumen dengan konten palsu. Kalau browser mengupdate address bar lebih dulu, hasilnya: address bar = google.com, konten = milik attacker.
Catat: setelah klik, perhatikan address bar. Sukses = address bar tetap/tertulis google.com TAPI kontennya halaman palsu di bawah (ada banner merah "HALAMAN PALSU"). Screenshot keduanya.

Varian B — javascript: URL lintas origin

Cara kerja: buka google.com di tab baru, lalu coba jalankan javascript: URL ke tab tersebut. Browser yang benar harus memblokirnya. Kalau konten google.com keganti, itu bug serius.
Catat: tab google.com kebuka? Kontennya berubah jadi halaman palsu atau tetap google.com asli? Screenshot hasilnya.
