PoC #4 — Push Notification Spoofing

Halaman ini HANYA untuk pengujian keamanan. Jangan dipakai untuk menipu orang.
Cara pakai:
  1. Upload dua file (poc4_pushnotif.html + sw.js) ke folder yang sama di GitHub Pages (wajib HTTPS).
  2. Buka di Edge Android, klik tombol 1 (daftar SW) lalu tombol 2 (minta izin).
  3. Klik salah satu tombol notif palsu.
  4. Untuk hasil terbaik: pakai tombol 2d, lalu segera tekan Home / kunci layar — lihat notifnya di notification shade / lock screen.
  5. Ulangi di Chrome Android, bandingkan.

Yang dicatat saat pengujian:
  1. Di notification shade / lock screen: apakah asal notif (nama situs / origin) terlihat jelas?
  2. Apakah notifnya meyakinkan sebagai notif aplikasi asli (bukan dari browser)?
  3. Apakah ikon palsu tampil? Apakah ada ikon pembeda (browser/gembok)?
  4. Klik notifnya — apakah membuka situs ini (situs jahat)?
  5. Bandingkan Edge vs Chrome: mana yang lebih jelas menunjukkan asal notif?
