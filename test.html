PoC #3 — Custom Tab Confusion

Halaman ini HANYA untuk pengujian keamanan. Jangan dipakai untuk menipu orang.
Cara buka sebagai Custom Tab:
  1. Jadikan Edge browser default: Pengaturan HP → Aplikasi → Aplikasi default → Browser → pilih Edge.
  2. Kirim URL halaman ini ke diri sendiri via WhatsApp/Telegram, lalu klik link-nya dari aplikasi itu — biasanya kebuka sebagai Custom Tab.
  3. Catat hasilnya, lalu ulangi dengan Chrome sebagai browser default dan bandingkan.
