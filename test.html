PoC #5 — Intent-based Attacks (Android)

Halaman ini HANYA untuk pengujian keamanan. Jangan dipakai untuk menipu orang.
Yang diuji: apakah situs web bisa (1) membuka aplikasi lain lewat intent://, (2) melakukannya tanpa tap pengguna (drive-by), dan (3) memicu download file .apk. Catat perilaku tiap browser.
Log aktivitas:
- siap -

1. Intent dengan tap (user gesture)

Klik satu-satu. Catat: apakah aplikasi langsung terbuka, ada konfirmasi, atau diblokir?

2. Intent TANPA tap (simulasi drive-by)

Klik tombol di bawah satu kali, lalu jangan sentuh apa-apa. 3 detik kemudian halaman akan menembakkan intent sendiri. Catat: apakah aplikasi terbuka tanpa interaksi tambahan?

3. Simulasi “fake update” (rekayasa sosial)

Ini simulasi iming-iming palsu ala serangan beneran. Tombolnya cuma membuka Play Store (target jinak) — yang diuji: seberapa meyakinkan alurnya.

4. Download file .apk

File yang diunduh sengaja BUKAN APK valid (isinya teks biasa) — jadi aman, tidak bisa ter-install. Yang diuji: apakah browser memberi peringatan “file berbahaya” saat download .apk, dan apa yang terjadi saat file-nya diketuk.
